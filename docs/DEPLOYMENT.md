# Deployment

This project is a static website with no build step.

## GitHub Pages

If this repository is connected to GitHub Pages:

1. Commit your changes.
2. Push to the branch configured for Pages.
3. Wait for GitHub Pages to publish the update.
4. Verify the live site in a browser.

`CNAME` should remain in the repo if a custom domain is being used.

## Pre-publish checklist

Before deploying:

1. Open `index.html` locally in a browser.
2. Check mobile and desktop layouts.
3. Verify the gallery images and contact links.
4. Confirm the `mailto:` and `tel:` links still work.
5. Confirm the lightbox opens and closes correctly.

## No build tools required

There is no bundler, package manager, or framework setup in this repository. Deployment is just publishing static files.
